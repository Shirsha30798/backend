# Video Sharing Platform

A backend application for an online video-sharing platform where users can upload, manage, discover, and interact with video content.

The project focuses on building a scalable and maintainable backend while exploring real-world software engineering concepts and best practices.

## Planned Features

- User registration and authentication
- User profile management
- Video uploads and management
- Video metadata (title, description, tags, etc.)
- Video search and filtering
- Likes and comments
- Channel subscriptions
- Pagination and sorting
